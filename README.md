# PACU Sales Receipt / Invoice Template

Minimalist commercial **Sales Receipt / Invoice** template designed for **PACU** (*Fly beyond the sky*).

## Included Files

- **`index.html` / `pacu_invoice_template.html`**: Interactive A4 Sales Receipt / Invoice editor & PDF generator.
  - **Direct Click-to-Edit**: Click any text field (Date, Receipt #, Customer Name, Address, Code, Description, Qty, Price, Tax Rate, Payment Method) to edit in place.
  - **Live Auto-Calculation**: Automatically recalculates line item `Amount`, `Subtotal`, `Sales Tax`, `Total`, bottom `Sales Receipt Slip` `Amount Received`, and English amount in words (`Nine Thousand Seven Hundred and NO`).
  - **Row Management**: Add product rows, add blank rows, remove rows, or toggle between European (`9.700,00`) and standard (`9,700.00`) number formats.
  - **Single-Page A4 PDF Export**: Click **打印 / 导出 A4 PDF** (`Cmd + P` / `Ctrl + P`) to save a single-page A4 vector PDF (the top toolbar is automatically hidden when printing).
- **`PACU_Sales_Receipt_MG-NJ-26NOV-L0-PW.pdf`**: Ready-to-print single-page A4 PDF for Receipt `#MG-NJ-26NOV-L0-PW`.
- **`PACU_Sales_Receipt_Template.xlsx`**: Spreadsheet template with built-in formulas for Apple Numbers and Microsoft Excel.
